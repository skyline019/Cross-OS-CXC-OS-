# 答辩提纲（15–20 分钟）

> 口径与 [THESIS.md](../THESIS.md)、[CONTRIBUTIONS.md](CONTRIBUTIONS.md)、题面再评估一致。  
> 禁止完成式：真 NVDIMM 通用、无条件掉电、真机千倍加速。

## 1. 开场（1 分钟）

题面四要件 → 本文交付：**并行 `/pm` 的 PM 文件子系统 + 可复现提交验收**。  
一句话尖刺：不可替代的是**方法学验收**，不是又一个双槽。

## 2. 系统（5 分钟）

1. 产品：保留根；`/pm` 普通 fd；COW + KV run；不经 virtio 日志。  
2. 提交：数据/元数据 persist → 8B 提交词；成功 `fsync` 才承诺。  
3. 设备：补丁 QEMU 独立 nvdimm（可 QMP）；MAP≠NVDIMM；默认 touch，可选 CBO。  
4. 现场（可选）：`make test-model` 或展示已有 `PMFS_RECOVERY_PASS` 日志一行。

## 3. 实验（5 分钟）

1. 正确性：recovery / vfs / model（杀进程≠掉电）。  
2. 架构面：matched roundtrip p50 约 2ms vs 22ms 量级（契约不等价）。  
3. 公平面：提示消融软件读请求↑、吞吐↓；非介质磨损。

## 4. 合题与边界（3 分钟）

| 题面 | 诚实落点 |
|------|----------|
| NVDIMM | 补丁路径有条件达标 |
| 去块抽象 | PM 路径达标；仍有页组织 |
| 掉电安全 | 假设+oracle；非物理掉电 |
| 架构级性能 | 软件路径量级差 |

## 5. 可能提问

- **为何不换根？** 题面可解释为并行子系统；换根超出体量且掩盖验收。  
- **为何不是掉电？** TCG/文件后端无持久域；我们验证声明模型。  
- **是否移植 FCS？** 约束下沉 + xv6 自研；尖刺在验收。  
- **性能能否发表为硬件结论？** 不能；文档已写明。

## 6. 收尾

展望：导师确认设备模型；论文按学校模板定稿；轨迹更紧接入模型。
