\chapter{相关工作}
\label{chap:related}

\section{教学操作系统中的块文件系统}

xv6~\cite{xv6book} 的 \texttt{fs+log} 以 inode、目录项、位图与日志检查点保证崩溃后可恢复。其 I/O 绑定 virtio 块设备与 bio；原生 \texttt{fsync} 主要等待全局日志提交，驱动未协商等价的设备 flush。本文将该路径作为\textbf{架构面}对照，并\textbf{保留为根文件系统}：PMFS 经固定挂载点 \texttt{/pm} 并行接入。

\section{持久内存文件系统与编程模型}

PMFS~\cite{pmfs2014} 与 NOVA~\cite{nova2016} 面向 PMEM 提供接近生产的文件语义；Strata~\cite{strata2017} 探索跨介质分层；BPFS~\cite{bpfs2009}、Mnemosyne~\cite{mnemosyne2011} 强调细粒度持久与编程抽象。本文取其「字节寻址 + 显式持久」动机，但收敛为教学体量的\textbf{可测子集}：固定挂载、有界资源、COW 对象图与 checkpoint，而非 Linux VFS 替身。

\section{崩溃测试与一致性验收}

CrashMonkey、PMTest、Witcher 等研究自动探索崩溃与一致性缺陷。本文不声称首创该类方法，而是在 xv6+QEMU 上构建\textbf{进程重启切点 oracle}、有界手写规格模型与源级写范围轨迹重放，使提交协议可复现、可负控。验收的是「声明故障模型下的协议行为」，不是物理掉电或全路径形式化证明。

\section{日志结构、切分与索引}

LSM 类结构~\cite{blsm2012} 与 Bloom 过滤~\cite{bloom1970} 广泛用于写入友好路径。本文 run 不可变、批量 seal、Bloom/fence 与有界 posting 属于同一设计家族；CDC 用于有界切分（无内容去重）。实现服务教学内核约束：页粒度、有限段数、粗粒度锁。

\section{作者前序工作与工程契约}

作者前序 \textbf{FCS}~\cite{fcsown} 提供双槽、不可变 run、写放大等约束；\textbf{Aurora}~\cite{auroraown} 提供量化键与 posting 等索引约束。二者源码不并入本仓库，xv6 侧为 C 自研重写。\texttt{ONBOX\_*} 串口契约手法~\cite{cxcos} 在本课题扩展为阶段码、recovery 脚本与 CI 目标。
